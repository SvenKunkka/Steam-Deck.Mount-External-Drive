## English project overview

A personal fork of scawp/Steam-Deck.Mount-External-Drive, containing scripts for mounting, unmounting and configuring automatic mounting of external USB SSDs on Steam Deck.

**Getting started:** Start with the repository scripts and the upstream [video guide](https://youtu.be/q9tiNzVWjVo). Check your device and mount target before following that workflow.

**Scope:** Upstream explicitly marks this as work in progress with possible bugs. This overview does not establish compatibility with current SteamOS; original authorship is preserved.
